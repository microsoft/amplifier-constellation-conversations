# Companion 0.13.0

Companion adds complete native application bundles for Windows, macOS and Linux
on x64 and ARM64. Open the packaged app to create a local Companion account,
select a saved contact or connect an existing agent, and configure any missing
voice settings in your browser. A standalone installation does not require
developer tools, a system Node or Python runtime, or a local Instance.

New personal installations use literal-loopback HTTP and an installation-local
password. Existing HTTPS and OS-account installations keep their access policy.
Selecting a saved contact preserves its profile, grants and room sessions.
Saving setup does not start a model session or call, request microphone or camera
access, or activate the paused speech changes.

The **App updates** page checks complete packages and records update and recovery
requests durably. An OS-managed worker can finish after the old app stops, and
the restored app has its own managed lifetime. Reloading the page reconciles the
same request. Calls, accepted work and uncertain effects can defer an update;
an enrolled installation keeps its existing updater owner.

Rollback restores the application bundle while preserving current accounts,
credentials, contacts, conversations and work records. If a replacement has
started but cannot provide authenticated status, recovery can stop only its
captured native generation and profile. It requires actual exit before exchanging
bundles and checks the previous application's health separately. Unknown outcomes
do not authorize a repeated launch or stop.

Native package verification checks the complete inventory and every file hash,
using bounded parallel workers that finish before return or replacement. Windows
launches, protected long paths and mutable data-journal publication retain their
qualified native handling.

See [Open Companion](../native-consumer-setup.md) for setup, updates and platform
qualification limits, and [native updates](../native-updates.md) for lifecycle and
recovery details. Hosted Windows x64 qualification runs on Windows Server;
ordinary Windows 11 qualification is recorded separately. Hosted qualification
does not establish a fresh consumer OS, reboot, physical media, publisher signing
or notarization result.
