# Conversations 0.13.2

Companion retains the original spoken request separately from its generated
delegation prompt when an agent supports negotiated source receipts. Accepted
work can refer back to that original request; a later correction has its own
source identity. Submission, accepted work, completed work and delivery to the
caller remain separate outcomes.

Saved action results remain available after a call ends, subject to the same
current access and source bindings. Reading a saved result does not submit work,
run a live observation, or turn an uncertain outcome into success.

Delayed display commands now carry the browser identity and human-interaction
revision they were based on. Companion checks both before accepting a command
and immediately before changing the display, so newer human navigation wins.
Routine presence updates and agent display changes do not count as new human
intent.

These changes reuse existing conversation, work-receipt and surface records.
They do not change native package CHECK, update deadlines, or the separate
background-CHECK design. Package, installation and actual voice-flow evidence
remain separately scoped.
