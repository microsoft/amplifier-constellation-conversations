# Conversations 0.10.0

Saved conversations now reconnect through an agent's advertised ACP resume capability without replaying history or silently creating a replacement session. Agents supporting only load retain their existing path. A failed resume preserves the saved binding and reports the failure without retrying the prompt.

This release also includes the accepted Companion preview work since 0.9.0:

- Foreground GPT-Live calls to existing ACP agents, with per-agent voices, hands-free controls, interruption and clearer call recovery and ending states.
- Optional camera capture, file sharing and a focused whiteboard, with readable result cards and durable saved times.
- Scoped Slack and Minecraft context and actions, preserving the requested connection, current observations and the meaning of confirmed versus uncertain outcomes.

Companion remains an optional preview with its own bridge and configuration; ordinary text conversations keep their existing behavior. Voice uses cloud audio and selected text context. Hanging up releases call resources but does not cancel already accepted agent or connector work. See [Companion setup and limits](../companion.md) before enabling it. Existing conversations remain private; this release does not change installation visibility or adopt a running installation automatically.

Linux x86_64 and aarch64 packages contain the checked executable, licensing and build provenance. Follow the repository's installation guidance for PAM and service configuration. The optional Companion bridge source is provided separately with its locked dependency manifest. It requires its documented Node/provider setup; it is not a self-contained voice runtime.

Validation uses the maintained Linux CI checks and disposable protocol/browser fixtures, plus the separately recorded native resume and MCP integration proofs. Synthetic-provider results do not certify live providers, production histories, all ACP capabilities or other operating systems. Exact release source, checked artifacts and checksums identify this publication; earlier measurements retain their original source identities.
