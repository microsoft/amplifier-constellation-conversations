# Conversations 0.14.0

This candidate replaces the separate browser Check and Apply steps with one
**Update** action. Open a newer native package, sign in to the existing
installation, and select Update. Preparation runs in the background and the page
shows the saved request's progress.

- Reloading or closing the page does not submit another update. A lost reply is
  reconciled with the original request.
- Active calls and accepted work can finish before the application stops.
  Unconfirmed outcomes remain visible for review. Cancellation is available
  before the stop boundary and waits for already-started preparation to settle.
- Installation, verification, restoration and explicit rollback use the existing
  whole-bundle lifecycle. Current accounts, contacts, sessions, credentials and
  work records are retained; rollback restores the prior application, not an old
  copy of user data.
- Opening the new package can present this flow for an existing 0.13.4
  installation without replacing its running server first. The temporary local
  update window uses the installation's existing account and restricted update
  controls.
- Installations managed by an enrolled updater keep that owner. Existing hosted
  setup and legacy update APIs remain available for compatibility.

The candidate does not activate the separately paused speech changes, start a
voice call, or change provider configuration. Source, package and actual Windows
qualification are tracked separately; these notes are not a publication or
readiness receipt.
