# Conversations 0.14.1

Removing an agent from a shared room now preserves the other agents’ saved
sessions and conversation progress. Their next message resumes the existing
session instead of starting over.

Old room access grants are revoked when the participant leaves. Remaining agents
receive fresh grants through the existing restore path; the removed agent loses
room access. Removal still waits for active room work to finish, and removing a
person retains its existing revocation behavior.

This patch includes the participant-detachment fix from #85. It changes no
provider configuration or native dependency selection and does not activate the
paused Companion work. Existing accounts, room transcripts and session identities
are retained.
