# Conversations 0.12.7

Pending request status now reaches Companion voice as compact facts rather than announcement prose. The original request identity, revision, pending-answer state and unknown external execution remain available for status questions without supplying another ready-to-speak acknowledgment.

The existing thinking delivery, voice prompt and conversation handling are unchanged. Retained receipts keep their original bytes and identities; accepted or uncertain deliveries are not reissued.

Validation includes 454 Rust tests (one ignored), 87 Python tests and strict lint and formatting checks. Focused regressions cover long request labels, source changes and preservation of older receipts. This release does not change the bridge or dependencies.
