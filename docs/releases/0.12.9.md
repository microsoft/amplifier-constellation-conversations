# Conversations 0.12.9

Companion reduces unsolicited updates while a connection action is pending. Status reads return to the agent that requested them without creating a second voice update. Queue and admission receipts stay inspectable without being narrated as progress. Actual replies, failures, blockers and uncertain outcomes remain available.

Background observations marked quiet or later stay in inspectable History and authenticated reads. Only an already-eligible proactive notice is sent as an unsolicited voice update. This honors the existing decision instead of assuming that thinking context will remain silent. Requested replies keep their independent delivery path.

When all action receipts for a backend turn are still submitting, queued or accepted, its interim narration stays in History and authenticated reads without entering the voice feed. A transport receipt establishes neither execution nor non-execution. Unknown or terminal receipts retain their existing answer path; independently delivered source replies remain available. Complete private replies can use ordered parts within the existing delivery limits, preserving original text and qualifications. Later observations do not repeat an already accepted reply or unchanged outcome. Corrections and changed status remain available, including a return to an earlier status. Historical uncertain deliveries are preserved.

The inline connection catalog and explicit discovery now share the same configured action routes and read operations. Read-only labels describe individual reads, so an available action route is no longer hidden by a read-only observation catalog. This adds no permission step, classifier or action authority.

A validated private source reply is labeled “Agent reply recorded,” while interruption, blockers and work outcomes remain separate facts. History shows observed position and time for recognized presence snapshots, with the full source available in Details. A still-pending request no longer causes a blanket claim that no result has arrived. Canonical observations, cards and source receipts remain preserved. Replies that cannot fit as a complete group stay available for reading, with an explicit notice instead of a selected success fragment. A source's reply describes what it reported; it is not independent proof of a physical result or what the listener heard.

Model settings, executable bridge helpers, credentials, sessions and work authority are unchanged. Public binaries are packaged from successful Linux ARM64 and x64 CI artifacts.
