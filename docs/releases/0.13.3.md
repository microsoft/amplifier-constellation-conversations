# Conversations 0.13.3

Companion checks whether a permission request is still waiting before sending
its queued notice. A notice that has become obsolete is superseded before it
reaches the call. If a notice was already sent or might have reached the
provider, Companion supplies a quiet update using the existing decision record.

An absent request alone leaves the decision unconfirmed. Resolving a permission
choice does not establish that the work is complete. Permission choices and
work authorization continue to use the existing controls and records.
