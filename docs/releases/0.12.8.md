# Conversations 0.12.8

Companion now avoids presenting the same recorded reply again when a later update contains that reply plus new information. It uses existing delivery records to omit only exact whole reply parts already accepted into the same call's voice context.

New replies, corrections and uncertain deliveries remain available. Full observations, cards and read history are preserved. This reduces redundant context without adding a new classifier, approval step or prompt.

This is context delivery deduplication, not proof that a person heard a reply. Ambiguous history and acknowledgments that arrive after a newer batch was queued can still leave a repeat.

The release changes no model settings, bridge, UI, credentials, sessions or work authority. Public binaries are packaged from successful Linux ARM64 and x64 CI artifacts.
