# Conversations 0.14.3

A stand-alone voice request to hang up is handled once. When call control has already accepted that request, Companion closes the call without sending the same words to the agent as another input. If you ask the agent to do something and then hang up, the agent still receives the requested work once.

Companion distinguishes a missing whiteboard report from a report of an empty board. When the browser has not reported which items are on the board, its contents are unknown. An explicit empty report records that the board was empty at the time of that report. Recent reports stay associated with their call and time, so an earlier observation or a saved card does not determine what is on the board now.
