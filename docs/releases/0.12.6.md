# Conversations 0.12.6

Companion now reports when a request could not start and keeps capability updates quiet.

- A clearly unsubmitted request produces one failure result. Its saved source is retained without an automatic retry, and previous work is unchanged.
- Partial, submitted, bound, or uncertain deliveries retain their existing outcome handling.
- Image capability facts come from the selected backend's actual initialization. They are retained immediately, then supplied as factual thinking context after successful session setup, using the existing delivery queue instead of a speech-interrupting instruction.
- Repeated observations do not repeat the update; newer observations replace only unsent capability facts.

This release does not change the live bridge, domain helpers, dependencies, ACP protocol, or storage schema.
