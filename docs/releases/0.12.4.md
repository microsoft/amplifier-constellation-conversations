# Conversations 0.12.4

Companion retains one quiet, source-bound fact while a saved request awaits its
answer. Voice can use that fact to answer a waiting-status question without
asking the backend again or inventing external progress. Repeated polling does
not create more announcements. A matching terminal result withdraws only its
unsent pending context; accepted and unknown deliveries remain in the audit.

A newer question no longer automatically makes an independently awaited answer
silent. Each result keeps its original source and remains eligible for speech
when the caller's conversational floor allows it. The image board retains its
separate current-result placement policy.

The bounded recorded-voice check returned the original delayed answer and
handled a later pending-status question locally. An early mixed style and
keep-checking refinement still caused one unnecessary backend prompt. That
failure remains recorded; this release does not claim complete elimination of
redundant delegation or verified mid-speech interruption.

The executable changes from 0.12.3; bridge files, helper files, dependencies,
model settings, and existing installation configuration are unchanged. No new
classifier, provider API, or work authority is introduced.
