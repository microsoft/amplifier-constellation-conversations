# Conversations 0.12.3

Companion can retrieve an agent's recorded reply to a request made in the same
private conversation when the Minecraft installation advertises the optional
source-reply capability. The original caller, request, conversation and source
revision must match. Public replies keep their existing behavior, and unrelated
private game messages remain excluded. Recorded text does not establish that a
reply was spoken, heard, or acted on.

Presence summaries now retain the source's observation limits: position and
activity alone do not prove current work or request fulfillment. Explicit
unsupported-completion fields stay visible without inferring missing facts.

Existing installations remain compatible with the base input capability.
Install this release's executable and the fixed `minecraft-instruction.py` and
`minecraft-observe.py` helper pair at the paths actually selected by the
installation before adopting a Minecraft producer with private source replies.
The helpers share existing request tracking and reply bounds; no new model,
permission, classifier, or session is introduced. Preserve installation-specific
configuration, credentials, routes, and unrelated bridge files.
