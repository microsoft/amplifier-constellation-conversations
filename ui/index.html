02

The conversation

Your audience, your choice

Conversations start private. Explicitly add people or agents when you want a shared room. Messages stay in this web experience. The agent can retrieve context through authorized providers. Reading another conversation does not post a message there.

A private conversation is not automatically shared with a group.

Connection details for tools and developers

Every conversation action and visible view state has an authenticated API. An assistant can select a conversation, change this view, draft a message, or send one with your authorization.

Action approvals appear to the person who sent the message. Each request expires and requires an explicit decision. Local file and command tools are optional. The owner must choose their workspaces and conversation audiences, and each operation needs your approval. The agent may also supply its own tools.

Connect another agent

Add an existing ACP endpoint. Your administrator can supply the connection settings; this does not install an agent or change its identity.

Use command paths and non-secret arguments only. Credentials belong in the connection’s protected configuration, never in view state.
